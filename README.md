# 통근버스 노선 앱

`통근버스_노선표_01-29_통합.xlsx`의 **전체_정류장** 시트를 기준으로 새로 만든 반응형 웹 앱입니다.

## 데이터 기준

- 노선 51개 / 정류장·기록 462개
- 정류장별 시간이 비어 있는 119개 기록은 임의 추정하지 않고 `시간 미기재`로 표시
- 원본의 `미운행` 2개 기록과 비고를 그대로 보존
- 원본에서 전부 비어 있던 탑승위치는 빈 값으로 보존
- 사용자 화면은 노선/지역/운행유형/시간대/정류장 검색, 즐겨찾기, 상세 타임라인을 제공
- 관리자 화면은 노선·정류장 수정/추가/삭제, JSON 내보내기·가져오기, 원본 복원을 제공

## 실행

Node.js 20 이상만 필요하며 외부 패키지 설치는 필요하지 않습니다.

```bash
npm run setup   # 관리자 비밀번호 최초 설정(10자 이상)
npm start
```

- 사용자 앱: `http://localhost:3000`
- 관리자: `http://localhost:3000/admin`

공유 서버에서는 HTTPS 역방향 프록시 뒤에서 실행하고 `.env`에 `COOKIE_SECURE=1`을 추가하세요. 기본 포트는 3000이며 `PORT=8080 npm start`처럼 바꿀 수 있습니다.

## 관리자 보안

- 기본 비밀번호가 없습니다. `npm run setup` 전에는 관리자 로그인이 차단됩니다.
- 설정 도구는 비밀번호를 scrypt 해시로 저장하며 평문 비밀번호를 저장하지 않습니다.
- 로그인 5회 실패 시 해당 접속 주소의 시도를 5분간 제한합니다.
- 로그인 세션은 HttpOnly/SameSite 쿠키로 관리하며 8시간 후 만료됩니다.
- 관리자 변경 요청에는 세션별 CSRF 토큰과 데이터 리비전 검사를 적용합니다.

## 데이터와 백업

- 현재 데이터: `data/routes.json`
- 원본 복원본: `data/original-routes.json`
- 저장 전 백업: `backups/` (최근 20개 유지)

관리자 저장 시 서버가 모든 노선 ID 중복, 필수값, 정류장 수, 데이터 크기를 다시 검사하고 정류장 순번을 1부터 재정렬합니다.
